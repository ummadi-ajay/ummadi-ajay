# Hi, I'm Ajay Ummadi

Founder and Managing Partner of [MakerWorks Lab](https://makerworkslab.in/), a robotics and Physical AI maker space in Malad East, Mumbai. I teach Arduino, micro:bit, Tinkercad, electronics and robotics, and I build with Hugging Face's open-source [LeRobot](https://github.com/huggingface/lerobot).

## What I'm building

- **[SO-101 Teleoperation Studio](https://makerworkslab.in/ajayummadi/projects/so-101-teleoperation-studio/)**: a web dashboard with a 3D digital twin for LeRobot SO-101 arms. Code in [lerobot](https://github.com/ummadi-ajay/lerobot/tree/dashboard-and-monitor/dashboard).
- **[Open-ear wired earbuds](https://github.com/ummadi-ajay/open-ear-earbuds)**: a parametric Blender design for 3D-printed open-ear earphones around a salvaged driver.
- **[LeRobot Training Monitor](https://makerworkslab.in/ajayummadi/projects/lerobot-training-monitor/)**: a live terminal dashboard for `lerobot-train`.
- **[SO-101 3D exploded view](https://huggingface.co/spaces/ummadiajay/so101-3d-exploded-view)**: an interactive view of the SO-101 arm, on Hugging Face.
